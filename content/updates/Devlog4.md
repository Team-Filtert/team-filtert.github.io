## Our First Dev Talk

A few days ago, we had our first Dev Talk. During the Dev Talk, the directors and I went through the current state of the game and talked about our plans for the different levels.

This talk was very important for us to get a clear understanding of what we need to work on next and to clear up any misunderstandings.

Another reason for this Dev Talk was to make it easier for new developers to get started. For that reason, we recorded the Dev Talk and made it available on our [YouTube channel](https://www.youtube.com/@TeamFiltered).

For now, we are keeping it unlisted, but we plan to make it public at some point in the future.

We also plan on releasing the uncut version of the stream when the first chapter is released.

If you are interested in joining us, you can still watch [the video](https://www.youtube.com/watch?v=VsUPUEL553w) here, but be warned that it may contain spoilers.

## Chapter 6 Changes

After thinking about it for a while, we decided to change the theme for Chapter 6.

Chapter 6 was originally planned to be a superhero-themed level set in a modern setting. But because we didn't have enough ideas for how to design it, we decided to change the theme.

The new theme will be a steampunk mystery level.

This doesn't have much effect on the story, as it was already planned to be a mystery level, now just with a more fitting and, hopefully, more interesting theme.

## We Still Need Help

If you are interested in developing a game, know how to use GitHub, and think you can help with level design, programming, or art, we would love to have you on board!

The main things we need help with are level design, programming, and art.

* We did get some more artists from the posters, but we still need animators.
* Level design is also a big problem. I can come up with ideas, but I need help with turning them into real concepts that the artists can work with.
* Right now, we only have one main programmer working on the project, and he could really use some help. Though this is currently the least important part of the project.

Even if you are not a developer, you can still help us by making suggestions and telling us what you think.

Also, if you know someone who might be interested in joining us, please tell them about our project!
